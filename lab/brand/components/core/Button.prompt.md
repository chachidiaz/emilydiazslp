Pill CTA button — use for every action link on the site; labels are lowercase and verb-first ("book a free consult").

```jsx
<Button variant="primary" size="lg" href="/evals">book a free consult</Button>
```

Variants: `primary` (plum, default), `secondary` (rose), `outline` (plum hairline on cream), `ghost` (underlined rose text link), `onPlum` (blush fill for use on plum sections). Sizes sm/md/lg. Never uppercase the label; never square the corners.
